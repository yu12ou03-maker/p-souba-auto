# 中古機相場：ランキング撮影 → Gemini解析 → 正常時だけDrive更新

毎朝9時JST（UTC 00:00）のGitHub Actionsで、パチンコ・スロットの価格ランキング各100件を読み、従来のGoogle Apps Scriptへレポート本文をPOSTします。GitHubの定期実行は遅延する場合があります。

## 取得方法

実サイトで確認されたランキングは`/krank_1.htm`と`/krank_2.htm`です。2026年10月の診断では、ログイン後の金額は不規則な画像ファイルで表示され、代替テキストもありませんでした。金額を文字HTMLから取得する方式は使いません。

ログイン後に順位・機種名・100件の表構造をDOMで確認し、表だけを25行ずつ撮影します。JavaScriptによる平均価格の表示を待ってから撮影します。数字画像が読み込めない、ログイン未完了、100件揃わない場合は中止します。長大なページ全体をGeminiに読ませず、見出し付きの4分割画像を各区分で使用します。全列の表を診断画像として残し、Geminiには順位・平均価格・前日差額だけを幅420px・倍率2で撮影した画像を渡します。機種名はHTMLで確認した参照情報から取得します。

Geminiには順位・機種名の参照情報と画像を渡し、同じ行の平均価格・前日差額をJSONで読み取らせます。各画像は別々の2回のリクエストで読み、金額・符号を含め結果が一致した場合だけ採用します。全200行の件数、連続順位、機種名、整数価格、差額を検証してからGASへ送信します。判読不能、欠落、異常値、読み取り不一致、APIエラーは送信しません。

2回一致してもAIが同じ誤読をする可能性は残ります。初回のdry-run画像・結果を人が確認することを推奨します。GAS側コードはこのリポジトリにはなく、`latest_report.txt`の更新先・サーバー側の正常データ検証は別途確認が必要です。

## 認証情報と実行

GitHub Secretsの`P_SOUBA_USER`、`P_SOUBA_PASS`、`GEMINI_API_KEY`を使用します。`GAS_URL`は任意で、未設定なら従来のデプロイURLを使います。`GEMINI_MODEL`をRepository variableで指定できます。未指定ではAPIから利用可能なモデルを取得し、旧コードと同じ`gemini-3.6-flash`を優先して選択します。一覧にない場合だけ、一覧に掲載された別のFlashモデルを使用します。モデルの実際の利用枠は生成時に確認されます。

旧SDKの終了と利用可能一覧にない固定モデルを避け、標準のHTTPS REST APIを使います。APIキーはURLに入れずヘッダーに設定します。生の例外、Cookie、HTML、ログイン画面、ID・パスワードをログや診断に保存しません。

```sh
python -m pip install -r requirements.txt
python -m playwright install --with-deps chromium
python -m unittest discover -s tests -v
python take_screenshot.py --capture-only
python take_screenshot.py --dry-run
# 検証を通った正常データをGASへ送信する場合:
python take_screenshot.py
```

手動Actionsと修復ブランチへのpushは既定で撮影のみです（Gemini・GAS呼び出しなし）。手動Actionsでcapture_onlyを無効、dry_runを有効にするとGemini解析まで検証します。定期実行だけは検証後に送信します。ブランチへのpushでmainは変更されません。修正をmainに反映して初めて定期実行が切り替わります。

サイトのHTTPSは、この環境から接続失敗・証明書エラーとなり、現在のフォームはHTTPを使用しています。ユーザーがHTTPログインを明示的に許可したため、既存のサイト動作に合わせてHTTPを使用します。サイトへ送るID・パスワードはHTTPでは暗号化されません。GAS・GeminiはHTTPSで証明書検証を維持し、認証情報を外部サイトへ送る画面遷移を禁止します。403/429等のアクセス制限を回避しません。

## エラー・診断・再試行

ページ取得とGeminiの一時的なサーバー／接続エラーは最大3回再試行します。不正なGemini JSONは同じ画像を最大2回解析します。APIの429・認証エラーは停止します。16回の通常API呼び出しを約13秒間隔で実行するため数分かかります。利用枠が足りない場合はDrive更新を止めます。404・503で利用できないモデルだけは、API一覧にある別のFlashモデルへ最大2回切り替えます。429や認証エラーではモデルを切り替えません。モデルを切り替えた画像は同じモデルで2回読み直します。

GASのPOSTは保存結果が不明なタイムアウトでも再送しません。成功応答`OK`だけを保存確認として扱います。診断画像はログイン画面を含まない表部分だけを`diagnostics/`に保存します。失敗理由・正常検証件数は秘密情報を含まないActions注釈にも表示し、アーティファクトは3日間保持します。

無料枠の画像解析生成上限が1日20回の場合、通常16回の生成で4回分の余裕を残します。再試行・他用途の利用で上限に達することはあり、成功は保証されません。上限到達時は停止し、モデル切り替えで429を回避しません。25行画像の実際の読み取り精度は、日次枠の回復後のdry-runで確認が必要です。
